# 访谈与问卷提纲

## 1. 使用说明

本提纲用于“研愿：校园调研与志愿活动平台”的需求调研，配套文档为 `docs/01-research-plan.md`。

| 对象 | 提纲章节 | 预计时长 |
| --- | --- | --- |
| 参与者 S1–S6 | 第 4 节 | 30–40 分钟 |
| 调研或志愿活动组织者 O1–O3 | 第 5 节 | 40 分钟 |
| 内容审核或名单管理人员 A1–A2 | 第 6 节 | 30–40 分钟 |

访谈要求：

- 采用半结构化方式，围绕最近一次具体经历展开。
- 不预先展示功能列表，避免诱导回答。
- 记录事实和时间线，原话加引号并标注问题号。
- 主访负责提问和追问，记录人负责摘录和待确认问题。

## 2. 开场与知情说明

1. 本次访谈用于软件工程课程设计，目的是了解校园调研与志愿活动的真实招募和参与过程。
2. 访谈不评价个人、社团或组织，只讨论流程与需求。
3. 记录会去除姓名、学号、工号、联系方式等身份信息。
4. 如需要录音会单独征得同意，受访者可随时跳过问题或结束访谈。

## 3. 提问与记录原则

| 原则 | 做法 |
| --- | --- |
| 问事实不问评价 | 询问最近一次如何报名、联系和确认时间 |
| 一次询问一个动作 | 按时间顺序还原流程 |
| 追问具体结果 | 询问耗时、通知方式、是否发生冲突 |
| 区分事实与推断 | 事实记录时间线，推断单独标注 |
| 保留反例 | 与团队假设矛盾的回答同样记录 |

常用追问：

- 最近一次具体是什么时候、什么活动？
- 当时先做什么、在哪里看到、之后发生了什么？
- 这一步大概花了多久？
- 如果没有人回复或临时取消，最后怎么处理？

## 4. 参与者访谈提纲

### 4.1 参与背景

- Q1 过去一学期参加过哪些调研、问卷、访谈或志愿活动？
- Q2 最近一次参与是什么活动，通过什么渠道得知？
- Q3 你参加调研和志愿活动的目的分别是什么？
- Q4 你通常同时关注多少类活动，信息来自几个群或平台？

### 4.2 发现与判断

- Q5 请还原从看到信息到决定报名的一次完整经历。
- Q6 你最先确认哪些条件，例如时间、地点、资格、时长、服务内容？
- Q7 哪些信息经常不清楚，需要额外询问？
- Q8 你是否遇到过报名后才发现自己不符合条件或时间冲突？
- Q9 你通常如何判断一个调研或志愿活动是否可信？

### 4.3 报名、确认与隐私

- Q10 报名需要填写哪些信息，是否在不同活动中重复填写？
- Q11 报名后多久得到确认，通过什么渠道？
- Q12 确认前后分别公开了哪些联系方式或地点？
- Q13 哪些信息你不希望在确认前公开，为什么？
- Q14 是否遇到过隐私被过度公开、联系人或地点被提前分享？

### 4.4 取消、候补与记录

- Q15 取消流程是什么，是否需要解释并获得同意？
- Q16 是否参加过候补，如何得知自己补上了？
- Q17 组织者取消或改期时如何通知你？
- Q18 参加结束后是否收到确认或参与记录？
- Q19 你希望保存哪些参与信息，用于查看、复盘或履历证明？

### 4.5 期望与收尾

- Q20 如果只能改进一个环节，你希望改哪一个，为什么？
- Q21 调研和志愿活动有哪些流程可以共用？
- Q22 还有什么重要情况没有提到？

## 5. 组织者访谈提纲

### 5.1 招募背景

- Q1 最近一次组织调研或志愿活动的主题、规模和周期是什么？
- Q2 招募对象有哪些，如何描述资格和参与要求？
- Q3 当前主要使用哪些群聊、表单、表格或平台？

### 5.2 发布与筛选

- Q4 请按时间顺序还原一次从发布到招满的过程。
- Q5 发布时填写和维护了哪些信息？
- Q6 报名者需要提供哪些资料？
- Q7 如何判断是否符合资格，平均需要花多少时间？
- Q8 不符合资格的申请如何处理，是否保留原因？

### 5.3 确认、名额与隐私

- Q9 如何确认时间、名额和参与名单？
- Q10 同一时段多人报名时如何决定，是否存在并发或超员？
- Q11 什么时候公开联系方式、地点或线上会议地址？
- Q12 如何避免将参与者信息发给无关人员？
- Q13 调研和志愿活动在隐私要求上有什么不同？

### 5.4 取消、候补与记录

- Q14 参与者取消或缺席时如何处理？
- Q15 如何寻找替补，通常需要多久？
- Q16 如何签到并判断参与者是否完成？
- Q17 调研和志愿活动的完成记录分别如何保存？
- Q18 是否发生记录遗漏、争议或无法追溯的情况？

### 5.5 期望

- Q19 招募过程中最耗时或最容易出错的是哪一步？
- Q20 你需要哪些统计信息，例如符合资格人数、接受邀请率和取消率？
- Q21 哪些操作必须人工确认，哪些可以自动处理？
- Q22 对统一管理调研和志愿活动，你有哪些顾虑？

## 6. 内容审核或名单管理人员访谈提纲

- Q1 哪些活动或组织者需要审核，依据是什么？
- Q2 如何发现虚假、重复或不合适的机会？
- Q3 举报通常包含哪些内容，最终如何处理？
- Q4 哪些操作需要查看历史记录或审计日志？
- Q5 名单、联系方式和地点等信息如何保存与删除？
- Q6 哪些隐私字段必须限制访问？
- Q7 如何处理同一用户重复报名、恶意取消或虚假签到？
- Q8 平台应提供哪些运营统计，但不暴露个人隐私？
- Q9 最担心系统上线后的哪类误操作或安全问题？

## 7. 流程还原脚本

选择至少一次调研招募和一次志愿活动招募，按以下维度还原：

| 观察项 | 记录要求 |
| --- | --- |
| 触点 | 群聊、问卷、表格、私聊、电话或现场 |
| 角色 | 发起人、审核人、参与者、运营人员 |
| 输入输出 | 每一步需要的信息和形成的记录 |
| 耗时 | 等待时间与人工操作时间 |
| 交接 | 信息复制、转述和丢失风险 |
| 异常 | 资格不符、取消、候补、超员和隐私问题 |

还原结果写入 `docs/research/findings.md`，并标注证据来源。

## 8. 参与者问卷提纲

### 8.1 发放要求

- 对象：参加过或关注校园调研、志愿活动的学生。
- 目的：量化验证访谈发现，不替代访谈。
- 方式：匿名线上问卷。
- 不收集姓名、学号、手机号和具体院系。

### 8.2 题目结构

| 区块 | 题量 | 题型 | 示例 |
| --- | --- | --- | --- |
| 参与情况 | 3 | 单选、多选 | 过去一学期参加调研或志愿活动的次数 |
| 信息渠道 | 2 | 多选 | 群聊、公众号、问卷平台、朋友推荐等 |
| 判断成本 | 3 | 单选 | 找到符合条件的机会通常需要多久 |
| 隐私 | 3 | 单选、多选 | 确认前不愿公开的信息类型 |
| 异常经历 | 4 | 多选 | 资格不符、时间冲突、未收到通知、取消等 |
| 期望能力 | 2 | 排序、多选 | 匹配、预约、候补、参与记录等功能优先级 |
| 开放题 | 1 | 填空 | 描述一次最不顺利的参与经历，不含个人信息 |

## 10. 提交前自查

- [ ] 覆盖参与者、组织者和内容审核或名单管理人员。
- [ ] 调研与志愿活动均有真实经历证据。
- [ ] 所有纪要已去除姓名、学号、工号和联系方式。
- [ ] 事实、原话和推断已分别标注。
- [ ] 与假设矛盾的证据已保留。
- [ ] 问卷统计口径和有效样本数已记录。
