## 背景

学生会志愿部干事，负责院内志愿活动的报名名单管理。和 A1（群管理员）不同，A2 管的是**院内固定合作的志愿活动**，有更具体的名单/报名/签到流程。

## 名单管理流程

组织者发布招募 → 参与者填问卷 → A2 导出名单到 Excel → 手动筛选 → 手动发通知 → 活动前整理签到表。

## 发现的问题与原话

- [A2-Q5] 名单和联系方式：目前全部存在 Excel 里（含姓名、手机、微信、年级），保存在学生会共享云盘
  - 事实：共享云盘 = 任何有访问权限的人都能看，没有分级限制
  - 补充：名单用完了也不会删，之前活动的报名名单一直在云盘里留着
- [A2-Q6] 需要限制的隐私字段：**手机号和家庭住址**（如果志愿活动涉及上门服务）
  - 事实：目前群公告里组织者会把自己联系方式公开，但**参与者的联系方式不应该被其他参与者看到**
  - 补充：有过一次情况——A 报名者看到 B 的联系方式后直接加好友推销自己的产品
- [A2-Q4] 需要审计的操作：名单的"谁导出、谁转发、谁改了"——目前 Excel 共享没有操作日志
- [A2-Q7] 恶意行为：遇到过同一用户报名 3 个不同时段的同一场活动，后来被组织者发现退了 2 个
- [A2-Q8] 希望的统计：**各年级参与志愿活动的比例**、**各类志愿活动的报名率**、**哪些时间段大家最有空**——但不要显示具体学号姓名
- [A2-Q9] 担心的安全问题：名单 Excel 被误发给无关的人（比如粘贴错微信群）
- [A2-Q1] 审核：院内活动由学生会统一发布，不需要审核（都是熟人和固定合作方）

## 异常场景

共享云盘的名单链接误发到了一个闲置微信群里，里面不是活动组织者的人也能看到完整名单，花了 1 小时才撤销链接。

## 期望

- 名单能**自动生成签到表**，不用每次导 Excel 手动做
- 联系方式**默认不公开**，只有组织者能看到
- 导出名单需要**权限 + 留痕**

无。
